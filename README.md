🐍 Python Quiz Game
This quiz game contains 10 interactive questions.
Players answer each question through the command-line interface,
receive immediate feedback after every response, 
and earn points for correct answers. 
At the end of the game, the final score is displayed,
allowing players to evaluate their performance.

✨ Features
Multiple-choice questions
Real-time score tracking
Simple and interactive command-line interface
Beginner-friendly code structure
Easy to modify and expand
